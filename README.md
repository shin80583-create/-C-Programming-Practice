# C Programming Practice

Beginner-friendly C programming practice with 24 numbered programs covering input/output, variables, conditions, `switch`, and `for` loops.

## Programs

- **Q1–Q3:** Basic calculations, marks/grades, and bill input validation
- **Q4–Q14:** `if`/`else`, even/odd, number checks, age, and pass/fail
- **Q15–Q16:** `switch` statements
- **Q17–Q24:** `for` loops, counting, multiples, odd numbers, and squares

## How to run

Open any `.c` file in Dev-C++ or another C compiler, compile it, and run it. Each numbered program is independent.

These are learning exercises. Some messages and assumptions are kept simple for practice; see each source file for its task.
