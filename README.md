# C Programming Practice

Welcome to my C programming practice repository! 👋

This repository contains **60 numbered C programs** that I use to practise programming, improve problem-solving skills, and learn C step by step.

## 📚 What is included?

The programs are saved in separate files, from `Q01.c` to `Q60.c`.

They are practice exercises covering C concepts at different stages. Depending on the program, these may include:

- Basic program structure and input/output
- Variables and data types
- Operators and calculations
- Conditional statements (`if`, `else`, and `switch`)
- Loops and number-based problems
- Functions
- Pointers and working with values through addresses

Please check each source file to see the exact question and code. Topics vary between programs.

## ▶️ How to run a program

1. Open the required `.c` file in **Dev-C++**, **VS Code with a C compiler**, or another C development environment.
2. Compile the program.
3. Run it and enter any input it requests.

Each numbered `.c` file is an individual practice program.
